# Sistema Acadêmico (Estilo SUAP Edu)

Este projeto é um sistema de gestão acadêmica desenvolvido com Django, Python, Bootstrap e PostgreSQL. Ele permite o gerenciamento de pessoas, instituições, cursos, disciplinas, matrículas, frequências, avaliações e ocorrências.

## Funcionalidades Principais

- **Gestão Completa:** Cadastro de alunos, professores, turmas e cursos.
- **Relacionamentos:** Inlines no painel administrativo para facilitar a visualização de dados vinculados.
- **Interface:** Listagem geral de dados em uma página HTML moderna utilizando Bootstrap 5.
- **Banco de Dados:** Preparado para PostgreSQL.

## Tecnologias Utilizadas

- **Backend:** Python 3.x e Django 4.2+
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **Banco de Dados:** PostgreSQL
